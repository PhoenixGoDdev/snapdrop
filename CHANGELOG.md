# Changelog

## 1.0.0

First public release.

- Capture an area, a window or the full screen; timers; multi-monitor and high-DPI aware.
- Floating thumbnail with drag-out into any app, folder, desktop or browser.
- Dropping on a terminal pastes the screenshot's file path (works around Windows Terminal refusing file drops).
- Editor: crop, pen, highlighter, arrow, box, text, pixelate, undo/redo, drag the edited image out.
- Smart saving: screenshots you drag somewhere are not duplicated into the screenshots folder; ones you ignore are saved there automatically.
- Settings window: start with Windows, save folder, file name, PNG/JPEG, clipboard, capture delay, custom shortcuts, thumbnail corner and duration.
- Installer (Inno Setup) that installs for the current user and downloads the .NET 10 Desktop Runtime if needed.
